n4s Signaturschlüssel erzeugen

Erzeugt ein Ed25519-Schlüsselpaar für die Signatur von n4s-Apps. Alles passiert lokal in diesem Browser-Fenster, es gibt keine Verbindung ins Internet und nichts wird gespeichert oder gesendet.

Dieser Browser unterstützt Ed25519 nicht. Bitte einen aktuellen Browser verwenden (Chrome oder Edge ab 137, Firefox ab 129, Safari ab 17) und die Datei per Doppelklick lokal öffnen.

1. Öffentlicher Schlüssel (darf weitergegeben werden)

Diesen Schlüssel an Claude schicken. Er kommt in das Plugin (includes/trust.php).

2. Privater Schlüssel (geheim, nicht weitergeben)

Nur als GitHub-Secret N4S_SIGNING_KEY im Repository n4s-plugin-admin speichern (Settings → Secrets and variables → Actions → New repository secret). Nicht in den Chat, nicht per Mail, nicht in eine Datei im Repository.

Nach dem Speichern des privaten Schlüssels dieses Fenster schließen. Der Schlüssel lässt sich nicht wiederherstellen; geht er verloren, wird einfach ein neues Paar erzeugt (der öffentliche Schlüssel im Plugin muss dann ersetzt werden).
